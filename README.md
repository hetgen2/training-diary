# Дневник тренировок (PWA)

Минималистичный дневник тренировок для телефона. Устанавливается как приложение, работает без интернета, данные хранятся только на устройстве: без аккаунтов, рекламы и лишних уведомлений.

## Возможности
- Запись силовых подходов: упражнение, вес, повторы.
- Запись упражнений на время (статика, бег, растяжка): минуты и секунды, встроенный секундомер.
- Тип дня (верх или низ) отмечается заранее и виден в календаре буквами «В» и «Н».
- При выборе знакомого упражнения показывается результат прошлой тренировки.
- Вкладка «Прогресс»: календарь с отмеченными днями тренировок и полный список подходов за выбранный день (с днём недели); режим «По упражнениям» с личным рекордом.
- Копия данных в JSON: сохранить и загрузить.

## Технологии
HTML, CSS, JavaScript без фреймворков и библиотек; localStorage; Service Worker (офлайн-режим); Web App Manifest.

## Запуск
```
python -m http.server 8000
```
Откройте http://localhost:8000. Установка на телефон требует HTTPS: проще всего выложить проект на GitHub Pages.

## Идея дизайна
Цифровой минимализм: одна запись подхода занимает несколько секунд, интерфейс не отвлекает.

## Планы
- Графики прогресса, заметки к тренировке.
- Нативный Android-клиент на той же модели данных.
