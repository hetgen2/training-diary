# Дневник тренировок (PWA)

Минималистичный дневник тренировок для телефона. Устанавливается как приложение, работает без интернета, данные хранятся только на устройстве.
## Возможности
- Запись силовых подходов: упражнение, вес, повторы.
- Запись упражнений на время (статика, бег, растяжка): минуты и секунды .
- Секундомер с обратным отсчётом 3 секунды перед стартом.
- Время тренировки за день: от первого до последнего записанного подхода.
- Тип дня (верх или низ) отмечается заранее и виден в календаре буквами «В» и «Н».
- Подсказки упражнений кнопками под полем ввода: только того вида (сила или время) и только из дней того же типа (верх или низ); самые частые идут первыми.
- При выборе знакомого упражнения показывается результат прошлой тренировки.
- Вкладка «Прогресс»: календарь с отмеченными днями тренировок и полный список подходов за выбранный день
- Копия данных в JSON: сохранить и загрузить.

## Технологии
HTML, CSS, JavaScript без фреймворков и библиотек; localStorage; Service Worker (офлайн-режим); Web App Manifest.
